Rozmiar modelu a jakość

Tło pokazuje punkty UZP za rozmiar (MoE liczone łącznie). Oś F1 jest powiększona do 0,985–1,000, bo prawie wszystkie modele mieszczą się w tym paśmie. O punktach decyduje rozmiar, nie jakość.

Przesuń wykres w bok, aby zobaczyć duże modele.

Wszystkie przetestowane modele

Kliknij nagłówek, aby posortować. Koszt to cały przebieg 36 dokumentów treningowych przez API (OpenRouter, USD).

Koszt przebiegu

Koszt 36 dokumentów. Najtańsze przebiegi mają duże modele MoE, ale za ich rozmiar jest 0 punktów. Reguły YAML kosztują 0 USD.

OCR skanów

F1 po OCR + ekstrakcji

Oś od 0,95. Oś jest przycięta, żeby było widać różnice.

Lokalny OCR a VLM przez API

CER (odsetek błędnych znaków) i czas na stronę. Mniej znaczy lepiej.

Lokalny PaddleOCR-VL działa bez sieci (tryb Reguły + OCR offline), ale na CPU jest wolniejszy i robi więcej błędów. Domyślnie OCR robi mały model wizyjny przez API.
